# Recursion — Introductory Implementation (C#)

A minimal project demonstrating the core idea of recursion in C#.  
This repository focuses on how functions can call themselves to solve problems  
by reducing them into smaller, repeated steps.

---

## Concept
Recursion relies on two parts:
- A **base case** that stops the function  
- A **recursive call** that continues the process

This pattern is used in many areas of computer science, including  
tree processing, divide-and-conquer algorithms, and backtracking.

---

## Purpose
A simple introductory project created to practice writing clear,  
easy-to-understand recursive functions and to build intuition  
for how recursive logic flows.
